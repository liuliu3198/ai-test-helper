# 测试用例模板

## 格式要求

1. 测试用例必须包含以下字段：
   - 用例编号（格式：TC-模块-序号）
   - 用例标题
   - 测试目的
   - 前置条件
   - 测试步骤
   - 预期结果
   - 优先级（P0/P1/P2）
   - 状态（待测试/通过/失败）

2. 测试用例必须使用表格格式输出

3. 每个功能至少包含正向用例和反向用例

## 示例

| TC-LOGIN-001 | 用户名密码正确登录 |
|--------------|-------------------|
| 测试目的 | 验证用户可以使用正确的用户名和密码成功登录 |
| 前置条件 | 用户已注册且账号未被锁定 |
| 测试步骤 | 1. 输入正确的用户名 2. 输入正确的密码 3. 点击登录按钮 |
| 预期结果 | 登录成功，跳转至首页，显示用户信息 |
| 优先级 | P0 |
| 状态 | 待测试 |
